Who This Is For

You've read v1 (or you have equivalent breadth: you understand tokens, context windows, RAG basics, and what an LLM actually is). Now you're picking up an agentic coding tool — Claude Code, Kilo Code, or Gemini CLI — and you want to wield it well, not just survive it.

This guide is for developers at that exact inflection point: past the "what is this" stage, not yet at the "I work this way automatically" stage. The goal is to close that gap.

Assumes v1. If you haven't read the Zero to Hero guide yet, start there. This guide builds on that mental model without re-explaining it.

The three layers

Foundations (Ch 1–5) — the mental model: agent loop, context, tools, model selection, surface choice. Methodology (Ch 6–11) — how you actually work: spec, plan, TDD, debug, review, parallel. Mastery (Ch 12–16) — the tools that make it real: Kilo Code, Claude Code, Gemini CLI, Superpowers, MCP.

See The Map (next section) for a visual overview of how everything connects.

Prerequisites

  • v1 mental model — tokens, context windows, LLM basics, RAG concept, what an agent is. You don't need to have memorized it; you need to have internalized the shape of it.
  • Basic git and CLI fluency — you can clone a repo, run commands in a terminal, and read a diff without stress.
  • Comfort installing tools — you can follow a README to install a CLI tool, set an API key, or add a VS Code extension without needing step-by-step hand-holding.
  • No specific language required — the worked example uses Python, but the methodology applies to any stack. Adapt freely.
